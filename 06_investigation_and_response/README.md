-[] Quy trình điều tra từng bước: nhận alert → thu thập bằng chứng (log, file, memory dump) → phân tích (process tree, network connection, registry) → kết luận (xác định tấn công hay false positive).

-[] Mẫu báo cáo sự cố (Incident Response Report) với các phần: thời gian phát hiện, mô tả sự kiện, bằng chứng, phân tích nguyên nhân, đề xuất khắc phục và phòng ngừa.
